# निंबाळकर ट्रेडर्स

Marathi-first digital portfolio for Nimbalkar Traders, Pimpri-Chinchwad.

## Publish with GitHub Pages
1. Open **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select `main` and `/ (root)`, then Save.

The catalogue is a sample list. Confirm product availability and pricing with the business before publishing.
